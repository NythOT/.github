## 🏰 Sobre o Nyth

O **Nyth** é um projeto de Open Tibia Server construído sobre o [Canary](https://github.com/opentibiabr/canary), com o mapa, as criaturas, os itens e os sistemas da versão **15.25**. O jogo é acessado pelo **cliente 8.60 com assets estendidos**, que enxerga todo esse conteúdo.

Nosso objetivo é oferecer um servidor estável e bem cuidado, com um site próprio para contas e comunidade e um canal direto com os jogadores no Discord.

---

## ✨ Principais Destaques

* 🗺️ **Conteúdo atual:** o mundo, as criaturas e os sistemas do Canary 15.25.
* 🖥️ **Cliente 8.60 estendido:** a interface do 8.60, com os assets que mostram o conteúdo novo.
* 🌐 **Site próprio:** contas, personagens, guildas, casas e biblioteca de criaturas e magias em [nyth.world](https://nyth.world).
* 💬 **Comunidade no Discord:** reporte de bugs e sugestões, com votação da comunidade.
* 📈 **Transparência:** o estado dos servidores fica público em [status.nyth.world](https://status.nyth.world).
